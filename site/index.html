HOW THE MEDIUM REFUSES

The Silence Rule

Gemma 4 writes the answer. Plain Python decides whether it may be spoken.

exhume.py

def cited(grave, ids): """Keep only ids that exist in this grave's evidence, in order, once each.""" real = {e["id"] for e in grave["evidence"]} return list(dict.fromkeys(i for i in ids if i in real)) def numbers_ok(text, grave, cites): """Every number in TEXT appears in the evidence it cites (04 and 4 count as the same).""" said = {int(n) for n in re.findall(r"\d+", text)} known = {int(n) for e in grave["evidence"] if e["id"] in cites for n in re.findall(r"\d+", e["text"])} return said <= known def guard(grave, reply): """Gemma's summon reply -> (answer, cites). No real evidence cited, or a number the cited evidence doesn't contain, means silence.""" cites = cited(grave, reply.get("cites", [])) answer = re.sub(r"\s*\[[^\]]*\]", "", reply.get("answer", "")).strip() # ids are shown from `cites` if reply.get("silent") or not cites or not answer or not numbers_ok(answer, grave, cites): return SILENT, [] return answer, cites

1

No evidence cited: silence.

2

A cited ID that isn’t in the evidence is dropped.

3

A number the cited evidence doesn’t contain: silence.
